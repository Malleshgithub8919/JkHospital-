# JK Hospital — Tanuku

A premium responsive React + Vite hospital website starter inspired by the supplied design reference.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code or Antigravity.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown in the terminal.

## Production build
Run `npm run build`.

## Important before publishing
- Replace address, phone, email, working hours, social accounts, and map placeholder with verified hospital information.
- Doctor names, portraits, facility photos, and hospital imagery are illustrative placeholders, not verified JK Hospital information.
- The appointment form performs client-side validation only; it does not send or confirm an appointment without a real backend/API.
- Images and fonts load from external sources and need an internet connection.
